# Brand font — New Astro

Drop the official **New Astro** font file here, named one of:

- `NewAstro.woff2` (preferred for web/PDF)
- `NewAstro.woff`
- `NewAstro.otf`
- `NewAstro.ttf`

`brand.css` already references these paths via `@font-face`, so once the
file is present every training section and the ARCARNA wordmark tagline
will render in New Astro automatically — no CSS changes needed.

Until the file is added, the manual falls back to a clean system sans.
